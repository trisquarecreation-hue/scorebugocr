02 // SUPPORTED WORKFLOWS

SEAMLESS BROADCAST INTEGRATION

Built from the ground up for live sports television, university athletics, and livestreaming setups using industry standard production tools.

vMix Web Controller Sync

Connects to the vMix Web Controller API (http://localhost:8088/api/). Auto-discovers active vMix title inputs and text fields, pumping clock and score updates with non-blocking async HTTP calls.

● Port 8088 Ready

OBS Studio File Broadcaster

Generates real-time text files (clock.txt, home.txt, away.txt, shot_clock.txt) in scoresight/out_files/ for OBS Studio Text (GDI+) sources set to "Read from file".

● Real-time text write

4-Corner Keystone Pinning

Handles angled stadium cameras shooting from the press box, stands, or floor. Interactive 4-corner perspective pins de-skew trapezoidal camera perspectives into a crisp, flat rectangular plane.

● 3D Homography Matrix

Capture Cards & IP Streams

Direct ingestion from USB HDMI capture cards (Elgato Cam Link, Magewell, generic USB dongles via DirectShow), video files (.mp4, .mov), and network streams (RTSP, SRT).

● DirectShow / RTSP / SRT

Monotonic Debounce Filter

Arena LEDs multiplex at high frequencies which can cause camera shutter flicker. The built-in monotonic debounce filter prevents digits from fluttering or falsely jumping backward.

● Temporal stabilization

Apple iOS Mobile View

Instant mobile scoreboard for iPhone and iPad via Safari Progressive Web App ("Add to Home Screen"). Sideline staff and producers can monitor digits wirelessly with zero latency.

● Mobile scoreboard sync
